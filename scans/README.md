# Nmap Scan Results

This folder contains the raw Nmap scan results generated
during the network enumeration and vulnerability assessment
of the Metasploitable 2 target.

## Scan Results

- `host-discovery.txt` — Host discovery results
- `port-scan.txt` — Open port scanning results
- `service-version.txt` — Service and version detection results
- `os-detection.txt` — Operating system detection results
- `vulnerability-scan.txt` — Nmap NSE vulnerability scan results
